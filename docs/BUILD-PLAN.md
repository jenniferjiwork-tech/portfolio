# Page-by-page build plan

1. Homepage: review desktop and mobile spacing, fonts, project captions and contact section. Supply the three video exports, posters and your LinkedIn profile URL.
2. About: create `about.html` using the existing Figma desktop and mobile frames. Supply the three personal photos if you want to include them. Connect both About navigation links.
3. Designing for conversion: create `projects/conversion.html`, add its media and connect the homepage card.
4. Cari: create `projects/cari.html`, add its media and connect the homepage card.
5. JENNY BIRD: create `projects/jenny-bird.html`, add its media and connect the homepage card.
6. Final checks: read all copy, verify every link, check mobile sizes, keyboard navigation, video controls, reduced motion, image descriptions and page titles. Confirm the CV behaviour and font licenses.
7. Hosting: put the source on GitHub and publish with GitHub Pages. Test the real URL on your phone. Add a custom domain later if desired.

At each stage: build → preview → compare with Figma → adjust → continue. Use one shared stylesheet and one shared script across the pages.
